[.description]
--
Make each task's `task.execute` span the current span while the task body runs, so that spans created by the task body (for example LangChain4j AI service calls or REST client calls) are children of the task span and belong to the workflow's trace.

Set to `false` to restore the previous behavior, where the task span is recorded but never current.
